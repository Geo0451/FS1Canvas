Widget positions

showwidgetxyoffset
Unchecking "show" doesn't erase the widget's position — it moves it off-canvas (x=250, y=300) only in the exported file, so you can re-check it later without losing where you'd placed it. Note: this hides the live number the watch draws for that widget. If a widget's icon is baked into your photo itself (not drawn by the watch), you'll need to paint over it in the photo separately.

Colours & fonts (experimental)

Load a template first.
The preview shows the real glyphs at their real positions (time = now, numbers = sample). Digits/labels are pictures stored in the file, so colour, font and size are baked in. Height rescales a set (widget W/H are rewritten to match). Font re-renders digits — pick a curated font (bundled in this file, renders the same on any device) or type the name of a font installed on this device instead. Own set gives a widget a private copy of the images (e.g. a different Minutes colour): it appends images and grows the directory, shifting the tables behind it — the most invasive edit here, untested. Hold Shift while dragging to disable snapping.

Widget library (experimental)

Adds a new widget into a spare slot of the currently loaded template — the widget table has room for up to 15, so this never restructures the rest of the file. Battery (icon style) imports an 11-frame pictorial battery asset (embedded in this tool) for templates that only have a numeric battery %. Duplicate numeric adds another digit-readout widget reusing whatever font/colour this template's numbers already use — handy for e.g. adding a Calories counter to a template that only has Steps and Heart Rate. New widgets land at (10,10) — drag them into place and give them a name/colour like any other.
